# Lunar Client version artwork

The version cards use the portrait thumbnails distributed with the Lunar Client launcher. The generic fallback uses the Lunar Client 1.14 thumbnail.

Source pattern:

https://launcherimages.lunarclientcdn.com/versions/thumbnails/26.png

https://launcherimages.lunarclientcdn.com/versions/thumbnails/1_21.png

All cards from Minecraft 26 through 1.0 follow the same
`versions/thumbnails/1_XX.png` naming scheme. The `1.8` and `1.7` cards are
also used for their supported Lunar releases, including 1.8.9 and 1.7.10.

The original artwork remains the property of its respective rights holders. Local copies are WebP-compressed for the launcher version picker.
